## 项目上下文摘要（地图规则更改）

生成时间：2026-09-02 08:49:35 +08:00

### 1. 相似实现分析

- **实现1**: `src/map/MapGenerator.cpp`
  - 模式：集中生成 `MapNode` 列表，并通过 `nextNodeIds` 表达向上一层的路线。
  - 可复用：`MapNodeType`、`MapNode::row`、`MapNode::nextNodeIds`。
  - 需注意：当前项目地图方向为 `row=0` 在底部，最后一层为 Boss。
- **实现2**: `src/app/Game.cpp`
  - 模式：地图点击后调用 `isMapNodeSelectable`，只允许从当前节点进入 `nextNodeIds` 中的节点。
  - 可复用：地图节点类型到战斗、事件、休息、商店场景的分发逻辑。
  - 需注意：硬编码修改起点节点类型会破坏生成器比例，应交回生成器统一控制。
- **实现3**: `tests/card_tests.cpp`、`tests/combat_tests.cpp`、`tests/room_tests.cpp`
  - 模式：测试均为独立可执行程序，通过 `assert` 或自定义 `require` 失败退出，再由 CTest 调度。
  - 可复用：新增 `MapTests` 直接链接 `map_system`，不引入新测试框架。
  - 需注意：测试输出和失败信息使用简体中文，保持项目文档要求。

### 2. 项目约定

- **命名约定**: 类与结构体使用大驼峰，函数与变量使用小驼峰，常量使用 `k` 前缀。
- **文件组织**: 地图逻辑位于 `src/map/`，地图点击集成位于 `src/app/Game.cpp`，测试位于 `tests/`。
- **导入顺序**: 先引入当前模块头文件，再引入标准库头文件。
- **代码风格**: C++17、头源分离、4 空格缩进、中文 UI 文案和测试说明。

### 3. 可复用组件清单

- `src/map/MapNode.hpp`: 地图节点类型、坐标和后续节点列表。
- `src/map/MapGenerator.hpp`: 地图生成入口 `generateMap(int rowCount)`。
- `src/app/Game.cpp`: 地图选择和场景跳转集成点。
- `CMakeLists.txt`: 已有测试目标声明位置。

### 4. 测试策略

- **测试框架**: CTest + 独立 C++ 测试可执行文件。
- **测试模式**: 生成 200 次 6 层地图，验证结构不变量。
- **参考文件**: `tests/card_tests.cpp`、`tests/room_tests.cpp`。
- **覆盖要求**: 出边数量、三出边节点总数、Boss 前休息层、无精英节点、商店路径上限、战斗与事件比例。

### 5. 依赖和集成点

- **外部依赖**: 地图生成仅依赖 C++ 标准库，不依赖 SFML。
- **内部依赖**: `Game` 使用 `MapGenerator` 生成地图，UI 读取 `nextNodeIds` 绘制连线。
- **集成方式**: 保持 `generateMap(int rowCount)` 接口不变，避免影响调用方。
- **配置来源**: 游戏当前在 `Game::startNewRun` 中生成 6 层地图。

### 6. 技术选型理由

- **为什么用这个方案**: 将地图结构约束收敛到生成器，调用方无需额外修正节点。
- **优势**: 路线和房间类型规则可测试、可复用，地图 UI 和场景跳转不需要新增分支。
- **劣势和风险**: 当前生成器未暴露 seed，因此测试通过多次随机生成覆盖不变量，不能断言固定地图形状。

### 7. 关键风险点

- **并发问题**: 无并发状态。
- **边界条件**: `rowCount <= 0` 返回空地图；游戏主流程使用 6 层地图验证完整规则。
- **性能瓶颈**: 节点数量很小，逐层扫描和 DFS 验证成本可忽略。
- **安全考虑**: 本任务不涉及认证、文件解析或网络边界。

### 8. 最新规则补充

- 首层 `row=0` 的所有节点固定为战斗节点。
- 首层不参与商店或随机事件分配，战斗/事件/商店只在其余普通层中随机组合。
- 地图节点不再绘制“战斗/事件/商店”等说明文字，只保留图标、连线和状态信息。
- 篝火背景改为外部图片 `assets/images/rest/campfire_background.jpg`。
- 场景音乐按状态切换：启动界面、地图、篝火、普通战斗、商人、Boss。
- 事件页的按钮布局与点击命中改为使用真实窗口尺寸，避免全屏错位。
