# 数据格式约定

本文档由 E 组维护，用于约定 `assets/data/` 下 JSON 数据的格式。A 组读取卡牌数据、B 组执行战斗效果、C 组显示 UI 时都以本文档为准。

## 1. 目录

```text
assets/data/
├── cards.json
└── enemies.json
```

## 2. cards.json

`cards.json` 是卡牌列表，根节点是数组。

### 2.1 卡牌字段

```json
{
  "id": "pommel_strike",
  "name": "剑柄打击",
  "type": "Attack",
  "cost": 1,
  "description": "造成 9 点伤害。抽 1 张牌。",
  "effects": [
    {
      "type": "damage",
      "value": 9
    },
    {
      "type": "draw",
      "value": 1
    }
  ]
}
```

字段说明：

```text
id：卡牌唯一标识，只使用小写字母、数字和下划线。
name：显示给玩家看的中文名称。
type：卡牌类型，当前允许 Attack、Skill、Power。
cost：能量消耗，0 或正整数。
description：显示给玩家看的中文描述。
effects：效果数组，按顺序执行。
```

### 2.2 效果字段

```json
{
  "type": "damage",
  "value": 6
}
```

字段说明：

```text
type：效果类型。
value：效果数值。
```

当前允许的效果类型：

```text
damage：造成伤害。
block：获得格挡。
draw：抽牌。
gain_energy：获得能量。
apply_vulnerable：给予易伤。
apply_weak：给予虚弱。
apply_strength：获得力量。
discard：弃牌。
exhaust：消耗当前卡牌。
```

### 2.3 机制卡写法

抽牌卡：

```json
{
  "id": "shrug_it_off",
  "name": "耸肩无视",
  "type": "Skill",
  "cost": 1,
  "description": "获得 8 点格挡。抽 1 张牌。",
  "effects": [
    {
      "type": "block",
      "value": 8
    },
    {
      "type": "draw",
      "value": 1
    }
  ]
}
```

加能量卡：

```json
{
  "id": "seeing_red",
  "name": "盛怒",
  "type": "Skill",
  "cost": 1,
  "description": "获得 2 点能量。消耗。",
  "effects": [
    {
      "type": "gain_energy",
      "value": 2
    },
    {
      "type": "exhaust",
      "value": 1
    }
  ]
}
```

## 3. enemies.json

`enemies.json` 是敌人列表，根节点是数组。

```json
{
  "id": "cultist",
  "name": "教徒",
  "maxHealth": 48,
  "intentDamage": 6,
  "description": "第一阶段普通敌人，适合测试敌人攻击回合。"
}
```

字段说明：

```text
id：敌人唯一标识，只使用小写字母、数字和下划线。
name：显示给玩家看的中文名称。
maxHealth：最大生命值，正整数。
intentDamage：默认攻击意图伤害，0 或正整数。
description：给开发者看的说明，可用于调试面板。
```

## 4. 维护规则

```text
新增机制优先增加 effects 类型，不新增大量零散字段。
新增字段前先通知 A、B、C 组。
删除或重命名字段前先更新本文档。
JSON 文件必须能被正常解析。
id 不要使用中文、空格或短横线。
```
