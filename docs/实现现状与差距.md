## 3. 接口和数据是否对应

### 已对应

- `MapNodeType::{Battle, Rest, Shop, Event, Boss}` 与 `Game` 的场景分派一致。
- `RestSystem`/`RestView`、`ShopSystem`/`ShopView` 的业务和 UI 分层一致。
- `EventDatabase`/`EventSystem` 与 `events.json` 的事件、状态、选项、效果结构一致。
- `ShopView::loadMerchantAnimation()` 按目录读取 `merchant_frames/frame_*.png`，这些 PNG 已被实际使用。
- CMake 已包含 `map_system`、`room_system`、`SFML::Audio`，并在构建后复制 `assets/`。

### 不对应或容易误用

- 文档中的 `MapState`、`SceneManager`、`Treasure`、`CardReward`、`Unknown` 等类型当前不存在；不要直接按这些示例写调用。
- 当前真实地图接口是 `std::vector<MapNode> MapGenerator::generateMap(int rowCount)`，不是文档中带种子的 `generateMap(int seed) const`。
- 当前真实战斗接口是单目标简化版 `bool CombatSystem::playCard(int handIndex)`，不是带敌人索引和 `PlayCardResult` 的多敌人接口。
- `assets/data/cards.json` 有 8 条记录，但卡牌运行时来自 C++ `CardDatabase`；两套数据不是同一个数据源。
- `assets/data/enemies.json` 有 4 条记录，但没有加载器；运行时默认敌人仍由 `EncounterDefinition{}` 创建为 40 HP 的邪教徒。
